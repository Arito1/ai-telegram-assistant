# AI Telegram Assistant — «Центр Красок #1»

Telegram-бот с AI-ассистентом, который отвечает на вопросы о компании
**«Центр Красок #1»** (centr-krasok.kz) — интернет-магазине лакокрасочных
материалов в Казахстане.

Бот работает в формате обычного чата: без команд и меню. Пользователь пишет
вопрос — бот отвечает на основе собранной и структурированной информации о компании.

## Что умеет

- Отвечает на вопросы: чем занимается компания, какие товары и бренды, где
  магазины, как работает доставка, кто клиенты, условия для дизайнеров и т.д.
- Помнит контекст диалога (последние 12 реплик на пользователя) — можно
  задавать уточняющие вопросы («а в Астане?», «а телефон?»).
- Не галлюцинирует: отвечает строго по базе знаний; если информации нет —
  честно говорит об этом и даёт контакты менеджера.
- Возвращает offtopic-вопросы к теме компании, защищён от prompt-injection
  («забудь инструкции» не работает).
- UX: приветствие с примерами вопросов, индикатор «печатает…», понятные
  сообщения об ошибках, поддержка длинных ответов (разбивка по 4000 символов),
  мягкий ответ на голосовые/фото/стикеры.

## Архитектура

```
ai-telegram-assistant/
├── bot/
│   └── main.py            # Telegram-бот (aiogram 3, long polling) + Anthropic API
├── data/
│   └── knowledge_base.md  # структурированная база знаний о компании
├── requirements.txt
└── README.md
```

Поток: сообщение пользователя → история диалога из памяти → запрос в
Google Gemini API с системным промптом, в который встроена вся база
знаний → ответ пользователю → сохранение пары реплик в историю.

База знаний небольшая (~6 КБ), поэтому она целиком помещается в системный
промпт — это проще и надёжнее RAG для MVP. При росте базы следующий шаг —
разбить её на секции и подмешивать релевантные через embeddings.

## Сбор информации

Информация собрана с официального сайта https://centr-krasok.kz/ (главная,
«Контакты», «Доставка»), очищена от навигации/рекламы и структурирована в
`data/knowledge_base.md` по разделам: о компании, услуги, ассортимент, бренды,
адреса и контакты, доставка и оплата, клиенты, преимущества. Отдельный раздел
фиксирует, чего в открытых источниках **нет** (вакансии, точные остатки) —
это дополнительная защита от выдумывания.

Соцсети компании: Instagram @centr_krasok, Facebook, YouTube (ссылки в базе знаний).

## Ограничение галлюцинаций

1. Системный промпт жёстко требует отвечать только по базе знаний.
2. Прописан сценарий «информации нет» → честный ответ + контакты менеджера.
3. Цены помечены как ориентировочные — бот предлагает уточнить актуальные.
4. Offtopic-вопросы не обрабатываются по существу.
5. Низкая температура не требуется: ограничение через инструкции + узкая роль.
6. Запрет на раскрытие промпта и смену роли.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Получите БЕСПЛАТНЫЙ API-ключ Groq
3. Установите зависимости и настройте окружение:

```bash
git clone <repo> && cd ai-telegram-assistant
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env   # и впишите свои токены
```

4. Запустите:

```bash
python bot/main.py
```

Бот работает через long polling — сервер и публичный IP не нужны, достаточно
любой машины с интернетом. Для продакшена: systemd-сервис или Docker,
переход на webhook и хранение истории в Redis.

## Стек

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram Bot API
- [Google Gemini API](https://ai.google.dev/) — модель `gemini-2.0-flash` (бесплатный тариф, карта не нужна)
- python-dotenv — конфигурация через `.env`
